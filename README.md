# E-Commerce Product Catalog App

# Project Overview

This is a simple full-stack E-commerce Product Catalog application that allows users to browse products, view details, search, filter, sort, and manage a shopping cart.


# Features Implemented

*  View all products
* Search products
*  Filter by category
*  Sort by price (Low → High / High → Low)
*  View product details
* Add to cart
*  Remove from cart
*  Wishlist feature
*  Basic login (localStorage)
*  Mock payment system
*  Responsive design



# Tech Stack Used

 # Frontend:

* HTML
* CSS (Amazon-style UI)
* JavaScript (Vanilla JS)

# Backend:

* Python
* Flask (REST API

# Database:

* JSON file (products.json)

---

# API Endpoints

| Method | Endpoint                      | Description        |
| ------ | ----------------------------- | ------------------ |
| GET    | /products                     | Get all products   |
| GET    | /products/<id>                | Get single product |
| GET    | /products/category/<category> | Filter by category |
| GET    | /search?q=keyword             | Search products    |
